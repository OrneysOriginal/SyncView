# SyncWatch

**SyncWatch** — настольное приложение для совместного просмотра локального видео: ведущий выбирает видео и управляет просмотром, несколько ведомых выбирают совпадающую локальную копию или получают файл по сети. Интерфейс написан на PySide6, воспроизведение выполняет libVLC, управление и передача файлов используют WebSocket.

Для Windows скачайте `SyncWatch-Windows-x64.zip` со страницы релиза, распакуйте его целиком и запустите `SyncWatch.exe` двойным щелчком. Папка `_internal` должна оставаться рядом с `.exe`; Python и VLC уже включены в готовый пакет.

Для GitHub подготовлен workflow **Build Windows application**, который собирает пакет и по полю `release_tag` создаёт черновик релиза.

Исходники и сборочные скрипты находятся в `syncwatch_mvp`; запускать приложение из исходников и тесты следует из этого каталога. Текущая версия — **0.2.0**, протокол **4**. В неё входят несколько ведомых, выбор локального файла с остановкой проверки при первом отличии, адресная передача с проверкой SHA-256, перемотка с подтверждением синхронизации, выбор порта и кода комнаты, экран запуска и собственная иконка. Проверка текущего кода: **192 теста пройдены**; границы готовности Windows-пакета описаны в [AUDIT.md](syncwatch_mvp/AUDIT.md).
