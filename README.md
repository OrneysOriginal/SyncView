# SyncView

В этом репозитории находится **SyncWatch** — настольный MVP для совместного просмотра локального видео с ведущим и ведомыми компьютерами. Интерфейс написан на PySide6, воспроизведение выполняет libVLC, управление и передача файлов используют WebSocket.

- [Инструкция пользователя и запуск](syncwatch_mvp/README.md)
- [Архитектура и протокол](syncwatch_mvp/ARCHITECTURE.md)
- [Результаты проверки и план улучшений](syncwatch_mvp/AUDIT.md)
- [Сборка для Windows и macOS](syncwatch_mvp/BUILD.md)

Для Windows предусмотрен запуск `SyncWatch.exe` двойным щелчком. [Как получить архив приложения](syncwatch_mvp/BUILD.md).

Для распространения готового приложения предусмотрен раздел [Releases](https://github.com/OrneysOriginal/SyncView/releases). Workflow **Build Windows application** умеет создавать черновик релиза с Windows-пакетом: при ручном запуске укажите новую версию в поле `release_tag`. [Инструкция публикации](syncwatch_mvp/BUILD.md#размещение-приложения-в-releases).

Запускать приложение из исходников и тесты следует из `syncwatch_mvp`. Текущая версия — 0.2.0-beta.1: несколько ведомых, адресная передача файла, полный SHA-256 и исправленный жизненный цикл комнаты. Результаты тестов и границы готовности релиза приведены в отчёте.
