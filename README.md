# SyncView

В этом репозитории находится **SyncWatch** — настольный MVP для совместного просмотра локального видео с ведущим и ведомыми компьютерами. Интерфейс написан на PySide6, воспроизведение выполняет libVLC, управление и передача файлов используют WebSocket.

- [Инструкция пользователя и запуск](syncwatch_mvp/README.md)
- [Архитектура и протокол](syncwatch_mvp/ARCHITECTURE.md)
- [Результаты проверки и план улучшений](syncwatch_mvp/AUDIT.md)
- [Сборка для Windows и macOS](syncwatch_mvp/BUILD.md)

Для Windows предусмотрен запуск `SyncWatch.exe` двойным щелчком. [Как получить архив приложения](syncwatch_mvp/BUILD.md).

Запускать приложение из исходников и тесты следует из `syncwatch_mvp`. Основные сценарии пока содержат известные ошибки; результаты тестов и границы проверки приведены в отчёте.
